# 🔐 Challenges : Protocoles non chiffrés

Ce dossier contient les résultats de l'analyse de captures réseau sur des protocoles non sécurisés.

**Objectif :** Extraire des secrets (utilisateurs, mots de passe) depuis des flux FTP, HTTP et Telnet en utilisant Scapy pour inspecter le contenu des paquets.
